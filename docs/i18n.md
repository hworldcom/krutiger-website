# Internationalization contract

KRUTIGER supports German (`de`) as its primary language and English (`en`) as its secondary language. Both languages use explicit URL prefixes. The root URL redirects permanently to `/de`; the application does not override an explicit visitor choice using browser-language detection.

## Ownership

- `src/i18n/config.ts` is the source of truth for supported locales and the default locale.
- `src/i18n/routing.ts` owns locale-aware path generation and corresponding-language paths.
- `src/i18n/dictionaries/` contains application-owned interface copy. Dictionary types make missing keys a compile-time failure.
- `src/i18n/metadata.ts` creates canonical URLs and reciprocal language alternates.
- `src/app/[locale]/layout.tsx` validates the locale and sets the document language.
- `src/lib/routes.ts` is the typed source of truth for route paths and navigation groups.

M1-03 owns the complete route map and localized placeholder pages. M1-04 will render the visible language switcher using the path helpers. M1-05 will supply localized footer copy.

## Translation behavior

- German is the editorial source language unless a content owner approves another source.
- Missing application translations must be added to both dictionaries; they must not fall back silently.
- Translation keys describe meaning rather than component position or styling.
- Brand names and user-entered values are not translated.
- Content rendered by bsport remains owned by bsport and is not passed through these dictionaries.

## Future Sanity boundary

Sanity will own localized editorial values such as page copy, class descriptions, coach biographies, FAQs, and SEO fields. The frontend will pass the active locale to the content adapter. Sanity will not own URL locale detection, application-interface dictionaries, or language-switching behavior.

The exact Sanity localization model—field-level values or document-level translations—will be selected when the CMS schemas are designed. Either model must return an explicit missing-translation state rather than silently mixing languages on a page.
